Chrome extension

See the shape of your data before opening the file.

Select a numeric TXT, CSV, or XLSX file in Google Drive and get an immediate line chart of its first two columns—without uploading the data to another service.

Processing stays in your browser
01

Select and preview

Click one supported file in Google Drive. The chart appears beside the file list.

02

Use the first columns

Column one becomes X and column two becomes Y. A single column uses its row number as X.

03

Copy or export

Copy the plotted values, copy the chart image, or save a clean PNG for reports and notes.

Supported data

The extension supports uploaded TXT, CSV, and XLSX files, including UTF-8, Big5/Windows-950, and BOM-marked UTF-16 text. XLSX files use the first worksheet and its first two columns. Native Google Sheets are not currently supported.

How access works

Google authorization uses the drive.readonly scope. The extension requests the file ID that you actively select, downloads that file through the Google Drive API, and processes it locally. It cannot modify, delete, or upload files. See the privacy policy for details.
