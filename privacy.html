Privacy Policy

Effective October 8, 2026

Data Plot Preview for Google Drive has one purpose: read numeric data from a TXT, CSV, or XLSX file selected in Google Drive, then plot or copy the first two columns in the user's Chrome browser.

Google user data accessed

The extension uses the Google Drive API to obtain the name, file type, and contents of the file the user actively selects. The Google authorization screen displays the drive.readonly scope, which technically permits reading Drive files. The extension implementation requests only the currently selected file ID. It does not list the entire Drive and cannot modify, delete, or upload files.

Use of Google user data

The selected file's contents are used only to parse numeric values, display a chart, copy the plotted columns, copy a chart image, or save a PNG at the user's request.

Processing, sharing, and retention

File contents are processed on the user's device. The extension has no developer-operated data server, does not sell data, and does not transmit file contents to advertisers or other third parties. It does not create a long-term database. A short-lived in-memory preview cache may be cleared when the file changes, the browser tab closes, the extension sleeps, or local authorization is cleared.

Authorization data

Google access tokens are managed by Chrome Identity. They are not exposed to the Google Drive webpage or sent to the developer. Users may clear the local authorization cache from the extension and revoke access from their Google Account's third-party connection settings.

Clipboard and PNG export

Clipboard access is used only after the user clicks a copy icon. The extension writes either the plotted numeric columns or a PNG image to the local clipboard. Saving a PNG creates a local browser download. Clipboard and exported image data are not transmitted to the developer.

Limited Use

Use and transfer of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Google user data is used only to provide the user-facing preview, copy, and export features described above.

Changes and contact

This policy may be updated when the extension's data practices change. The effective date will be updated on this page. Support contact information is provided in the Chrome Web Store listing.
